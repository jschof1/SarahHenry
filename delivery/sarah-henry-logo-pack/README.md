## Notes for your printer

- **Colour profile.** The CMYK files were separated using the macOS Generic CMYK profile, which is very close to **FOGRA39 / ISO Coated v2** (the UK & EU print standard). If your printer needs a different profile (e.g. GRACoL or SWOP for US work), they can re-separate from the supplied vector / PDF files in their own colour-managed workflow.
- **Hero brand colour.** Lilac 700 — `#5E4777` / CMYK `67 / 77 / 18 / 12` / Pantone near-equivalent **2695 C**. Use this whenever a single brand colour is required.
- **Transparency.** EPS Level 3 supports image transparency. If a print partner is using legacy software that flattens transparent EPS onto white, give them the matching PDF instead — it preserves transparency better.
- **The colour logo.** This is a vector container wrapping a high-resolution colour image (so the watercolour wash, line-art rose and thistle, and the script wordmark all reproduce faithfully). It is print-ready at any size up to roughly **A3** at 300 dpi without softening.
- **The mono logo.** This is a true infinite-scale vector trace — use it for any single-colour reproduction (foiling, embroidery, signage, fax-grade jobs).

## Notes for your designer

- The colour palette and Pantone references are in `docs/brand-colours.pdf`.
- All vector files use the original 1376 × 768 aspect ratio.
- The mono SVG was traced with potrace from a tightly-thresholded version of the master image; the line art and "Sarah's Signature Ceremonies" wordmark are preserved as resolution-independent paths.
